# MeetCal LLC

MeetCal LLC is a compnay owned by Maddisen Mohnsen that offers 3 distinct products for athletes, coaches, and spectators of USA Weightlifting and USA Masters.

### MeetCal
MeetCal is an iOS and Android app built with React Native and Expo. It takes all the messy PDFs of competition like the schedule, start list, records, QTs, A/B standards, rankings, athlete PRs, and more and puts it into a nice, simple app.

### MeetCal CLI
MeetCal CLI is currently in v1.0.0 and actively being developed. It takes all the data from MeetCal and throws it in the terminal. It also allows for more fine grained deep dive of your clubs or WSOs results at national meets.

### War Games
War Games is a React website that allows weightlifting coaches to practice their backroom counting and strategy by playing simulated competitions. These competition can be played against the random computer, or you can play with the exact athletes and data from any session of any national meet.
